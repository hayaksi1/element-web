# Paths in a modify/delete conflict where the DELETION is the correct answer.
#
# Either direction: upstream deleted a file a branch still edits, or the fork deliberately
# replaced an upstream component and a rebuild keeps re-offering it.
#
# git rerere records content conflicts only. A modify/delete is a TREE conflict, so it
# is never cached and would stop every single rebuild forever. Listing a path here tells
# the sync script to accept upstream's deletion for that path and carry on.
#
# This is not a blanket -X ours. Each line is a deliberate, reviewed decision that the
# file is gone upstream for good and the branch's change to it is obsolete. Removing a
# feature's behaviour is a real consequence -- if the branch's change still matters, port
# it to whatever replaced the file instead of listing it here.
#
# Format: one repo-relative path per line. # comments and blank lines ignored.
