# Upstream contribution branches, in merge order.
#
# These back pull requests against element-hq/element-web. They are MERGED into
# master as-is and are NEVER rebased, amended or pushed by the sync
# script -- rewriting one detaches its review threads and re-fires its CI.
#
# Do NOT list a branch whose PR was already MERGED upstream. Upstream squash-merges,
# so its content is already in develop; re-merging it re-applies stale code and can
# silently revert later upstream work. pr/desktop-titlebar-drag is the cautionary
# case: absorbed by #33991, then rewritten by #34419 and #34704, so re-merging it
# would undo both.
#
# Order is by file-overlap cluster, largest first, oldest commit first within a
# cluster, so conflicts land together and rerere can replay them.
#
# Deliberately excluded, with reasons:
#   demo/media-tabs                     duplicate of pr/search-media-tabs (#34007)
#   e2e/full-size-threads               develop-derived scratch, 345 commits ahead
#   feature/remove-message-hover-highlight  develop-derived scratch, 348 ahead
#   pr/desktop-warn-before-quit-v2      same 5 files as the open #33995
#   pr/macos-notification-sound         re-applies invite work absorbed by #34575
#   pr/pinned-banner-edits-fix          byte-identical head to an absorbed branch
#   pr/room-list-max-width-persist      zero commits of its own
#   pr/search-infra                     self-declared WIP; folds into pr/search-stepping
#   ...and all 49 branches whose PR is MERGED.
#   pr/search-cmdf-default              subset of pr/search-cmdf-toast
#   pr/search-stepping                  subset of pr/search-from-filter
#   pr/search-from-filter               subset of pr/search-order-toggle
#   pr/search-order-toggle              subset of pr/search-jump-to-date
#   pr/search-jump-to-date              subset of pr/search-top-bar
#
