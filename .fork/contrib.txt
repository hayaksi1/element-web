# Upstream contribution branches, in merge order.
#
# These back pull requests against element-hq/element-web. They are MERGED into
# combined/integration as-is and are NEVER rebased, amended or pushed by the sync
# script -- rewriting one detaches its review threads and re-fires its CI.
#
# Do NOT list a branch whose PR was already MERGED upstream. Upstream squash-merges,
# so its content is already in develop; re-merging it re-applies stale code and can
# silently revert later upstream work.
#
# One branch per line. Order matters: branches touching the same files should sit
# together so conflicts cluster and rerere can replay the resolutions.
# Blank lines and # comments are ignored.
